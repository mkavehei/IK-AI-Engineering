STREAMLIT: KEY POINTS AND APPLICATIONS
======================================

Streamlit is a free Python tool that turns a single Python file into a web page, without any knowledge of HTML or web design. Each line such as st.title(), st.text_input(), st.file_uploader() or st.dataframe() places one piece on the page (a heading, a typing box, an upload button, a table), in the same order as it appears in the file. The most important idea is that Streamlit runs the whole file again from top to bottom every time the user types, clicks or uploads something, so the page always shows the latest result. A typical app has six parts: imports, page setup, a sidebar for settings (like an API key), the main inputs (upload or question box), the work (reading data or calling an AI), and showing the result. You start an app with "streamlit run app.py", it opens in the browser at localhost:8501, and it stops with Ctrl + C in the Terminal.

Streamlit is not limited to CSV files. It can work with any data, because Streamlit only builds the page, while other add-ons read the data: pandas for tables (CSV, Excel), other libraries for text, PDFs, images or audio. That is why it is so popular in AI courses and among data and AI engineers: in a few minutes you can build a "chat with my CSV" or "chat with my document" app, an image tool, a speech-to-text tool, a chatbot, a dashboard with charts, or a quick demo to show a model to other people. Its strengths are speed and simplicity for demos, learning projects and small internal tools. It is not the best choice for large public websites with many users, accounts and a fully custom design; those are usually built with other web tools.
